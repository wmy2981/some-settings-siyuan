# Some Settings

> **個別にオン・オフできる** SiYuan の強化機能をまとめたものです。各設定項目は、それぞれ単独で有効・無効にできます。

フィードバックや機能の提案を歓迎します。ぜひ[Issue を作成](https://github.com/wmy2981/some-settings-siyuan/issues/new/choose)してください。

## 機能一覧

カテゴリは、各設定が作用する SiYuan のネイティブ機能ごとに分かれており、設定パネルのタブと一対一に対応しています。

### AI

* エージェントパネルに DeepSeek の残高を表示
* Enter でエージェントのメッセージを送信
* エージェントの候補プロンプトを非表示
* エージェントの思考ヘッダーを固定
* エージェントのツール呼び出しの詳細
* エージェントの思考を翻訳

### エディタ

* コードブロックの言語を記憶しない
* Web リンクを開く前に確認
* アセットメニューにファイルサイズとメタ情報を表示
* スラッシュメニューから assets にファイルを作成
* 録音中の通知の代わりにフローティングウィンドウを表示
* タイトルアイコンに見出しレベルを表示
* インラインコードのコピーボタン
* 選択ツールバーを非表示

### ドキュメントツリー

* 最初のドキュメントアイコンを固定
* ブックマークからドキュメントを開いたときに前回の位置へ移動
* 開いているドキュメントのアクセント
* ドキュメントツリーのタイトルでインライン Markdown を表示
* タブのタイトルでインライン Markdown を表示
* 未使用のタブを閉じる
* アウトラインの見出しレベル制限
* モバイルのドキュメントツリータイトルを 3.8.9 の大きさに戻す
* デイリーノートを直接作成
* 新規ドキュメントを固定の場所に作成

### 外観

* モーダル背後のぼかし
* 終了画面のぼかしを維持
* デスクトップのコマンドパネルを細く
* モバイルのドックバー背後のぼかし
* モバイルのバーを滑らかに
* モバイルの候補パネルを高く
* ドロワーの高さを内容に合わせる
* モバイルで同期ボタンを常に表示
* モバイルのドロップダウンを SiYuan ネイティブのスタイルに
* モバイルの長押しメニューにラベルを表示
* モバイルでブロックアイコンを常に表示
* モバイルの終了ボタンを非表示

### 接続

* 接続切断パネルの再接続ボタン
* 切断後に自動で再接続

### 設定

* 終了前に確認する
* Aliyun OSS バケットの使用量
* コードスニペットのシンタックスハイライト
* デスクトップで F12 により開発者ツールを開閉
* コンソールログビューア

### マーケットプレイス

* マーケットプレイスパッケージのカスタムアイコン
* 作者でマーケットプレイスパッケージをブロック
* ダウンロード済みマーケットプレイス一覧の寄付ボタンを非表示
* モバイルでプラグイン設定のドロワーを全画面で開く

### このプラグイン

* 詳細ログ出力
* 利用できない設定を表示
* 設定パネルの検索
* このプラグインの設定を消去
* このプラグインについて
* このプラグインの設定をインポート・エクスポート

## インストール

1. **SiYuan マーケットプレイス**：**設定 → マーケットプレイス**を開き、_Some Settings_ を探してそのままインストールします。
   以後の更新も同じ経路で届きます。
2. **リリース版のダウンロード**：[releases](https://github.com/wmy2981/some-settings-siyuan/releases) から `package.zip` を
   ダウンロードし、`<workspace>/data/plugins/some-settings-siyuan/` に解凍して、`plugin.json` がそのフォルダの直下に
   来るように配置します。その後 SiYuan を再起動してください。
3. **ソースからビルド**：リポジトリをクローンし、`npm install` を実行してから `npm run build` を実行します（Node 24 以降）。
   ビルドは `package.zip` とフラットな `dist/` を出力するので、どちらかを同じフォルダに解凍してください。

次に **設定 → マーケットプレイス → ダウンロード済み → Some Settings → 設定** を開きます。入口はここだけで、
プラグインはトップバー、ステータスバー、ドックにボタンを追加しません。パネルの開き方は SiYuan 自身の
**設定画面を独立したウィンドウで開く**設定に従います。オンのときは独立したウィンドウ、オフのときは通常の
設定ダイアログです。

## 開発

Node.js 24 以降が必要です。リポジトリをクローンしたうえで、次を実行してください。

```bash
npm ci              # 依存関係をインストール
npm run dev         # ソースを監視し、index.js / index.css / i18n をリポジトリ直下に出力
npm run build       # 機能宣言を検証してから dist/ と package.zip をビルド
npm run check       # 機能宣言とすべての言語ファイルだけを検証
npm run typecheck   # TypeScript の型チェック
npm run lint        # ESLint
npm run format      # dprint でフォーマット（format:check は検証のみ）
npm test            # ユニットテスト（vitest）
```
