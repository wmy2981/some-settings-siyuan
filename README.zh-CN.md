# 一些设置

> 一批**可独立启停**的思源增强功能：每个设置项都能单独启用、禁用或隐藏。

* 最低思源版本：`3.8.6-alpha.4`
* 适用环境：桌面端、移动端、桌面窗口、浏览器；后端不限
* 只读 / 发布模式下本插件不生效

## 开始使用

打开方式：**设置 → 集市 → 已下载 → 一些设置 → 设置**，这是唯一的入口 —— 插件不在顶栏、状态栏、
停靠栏注册任何按钮。

面板里的每一项都以一个开关开头，**默认全部关闭**，按需逐项打开。改完点「保存」，点「取消」则全部丢弃，
有未保存的改动时关闭会先确认。关掉某个功能会把它**完整卸载**（样式、监听、注入的节点全部撤掉），
不需要重载插件；只在单端生效的功能，在另一端的设置面板里不会出现。

## 注意事项

* 保存以**整个面板**为单位：改多少项都只在点「保存」时写盘，点「取消」什么都不写，有未保存的改动时关闭会先确认。
  面板里没有单项重置按钮，要把某一项恢复默认值，可以先导出配置、改好再导入，或用「清除本插件配置」清空全部。
* 「立即重连」与「断连后自动重连」的做法是**重载前端**：思源没有给插件重建主 WebSocket 的入口，
  所以探测到内核恢复后会整页重载。文档内容始终由内核持有并随时落盘，重载不会丢笔记。
* 控制台日志只在开关打开之后才开始收集 —— 插件加载阶段、以及打开开关之前的日志不会被记录。
  要抓启动期的问题，先打开开关，再复现一次。
* 「阿里云 OSS 存储桶使用数据」的查询由前端直接发出：桌面客户端不受同源策略限制，移动端与浏览器里
  需要在桶上配置 **CORS 规则**（放行思源的来源与 `x-oss-date`、`Authorization` 请求头），否则只会得到一句查询失败。
  数据由阿里云统计，可能滞后一小时以上；只有桶的拥有者能读到它。按钮按**已保存**的 S3 配置判定，
  改完 Endpoint 要等它保存（离开输入框）后才会出现。
* 行内代码复制按钮的「悬浮显示」在移动端按**光标位置**判定（移动端没有 hover）：手指点在或选到某段行内代码、
  光标落进去时按钮就出现。点按钮不会抢走编辑区焦点，键盘与光标都留在原处。
* 页签标题与文档树标题的行级 Markdown 只把语法字符**隐藏**在 DOM 里，标题原文没有改变，
  所以各处读到的仍是原文（拖拽提示、`document.title`、加密笔记本的解锁提示）；关掉功能就回到纯文本标题。
* 书签跳转只接管**整篇文档**书签上的干净左键单击；带修饰键的单击保持思源自己的行为
  （新页签、分屏、不跳转），加在块上的书签完全不受影响。
* 退出确认拦的是主菜单的「退出应用」与「关闭窗口即退出」时的关窗。托盘退出不询问；
  连接**远程内核**时的退出、以及请求本身失败时宿主的兜底退出，没有任何插件 API 能够到。
* 录音浮窗只换界面：权限、MP3 编码、上传与插入音频块全都还是思源自己的代码，
  而思源的录音器没有暂停语义，所以浮窗只提供停止。
* 移动端下拉用原生样式是尽力而为：个别内核 / 系统组合仍可能弹出系统自己的下拉弹层，
  此时选择器行为与未启用插件时完全一致。
* 资源信息行直接落在右键菜单里（与思源自己的「更新于 / 创建于」同级，前面有一条分隔线），
  不进「插件」子菜单；并且只有工作区资源（`assets/…`）有文件大小与修改时间，外链与 `data:` URI 没有。
* 打开设置面板时不自动聚焦：在你点中某个控件（或它的标签、按钮）或按下按键之前，
  焦点一直留在弹窗本身，所以第一次按键不会落进任何控件、移动端也不会顶起软键盘 ——
  这正是这个开关的用途，不是故障。只点标题栏或侧栏分类不算「动过手」。
* 「固定首次添加的文档图标」会写入文档的 `icon` 属性，并就地更新标题区、文档树、固定页签与大纲里的图标。
* 「代码片段编辑区高亮」依赖思源自己的 highlight.js；它迟迟加载不出来时插件会主动拆掉高亮层，
  编辑框回到普通的纯文本状态，不会留下看不见字的输入框。
* 「关于本插件」里的仓库链接同样会经过「外链跳转前确认」，和其它外链一样。
* 「插件配置导入导出」导入成功后会重新载入前端：此时设置面板里还留着导入之前的草稿，
  **导入之后不要再点「保存」**，否则会把旧值写回去。
* 「『引用面包屑』插件引导」在你没装那个插件时打开它的集市页面；本设备关闭集市时只提示一句。
