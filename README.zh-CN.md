## 安装

1. **思源集市** —— 打开 **设置 → 集市**，找到「一些设置」直接安装；后续更新也走这里。
2. **发行版下载** —— 从 [Releases](https://github.com/wmy2981/some-settings-siyuan/releases) 下载
   `package.zip`，解压到 `<工作空间>/data/plugins/some-settings-siyuan/`，让 `plugin.json` 直接躺在这个目录下，
   然后重启思源。
3. **自行编译** —— 克隆仓库后 `npm install`，再 `npm run build`（需要 Node 24 及以上）；构建产物里有
   `package.zip` 和扁平的 `dist/`，把其中任一个解压到同一个目录即可。

然后打开 **设置 → 集市 → 已下载 → 一些设置 → 设置**，这是唯一的入口 —— 插件不在顶栏、状态栏、
停靠栏注册任何按钮。

## 注意事项

* 设置改完即写入该功能自己的配置文件，没有保存按钮，关掉面板也不会丢改动；也没有单项重置，
  恢复某一项只能导出配置改好再导入，或者清除全部。
* 面板记住上次关闭时的页签，下次打开回到那一页；该页签已不可用时回到第一个页签。
* 搜索框（桌面端在内容区顶部、移动端在标题下方）同时搜分类、功能与设置项，命中的功能连同它的全部设置
  一起显示并高亮；`Ctrl/Cmd + F` 或 `/` 聚焦，`Esc` 或输入框里的清除图标只清空搜索、不关面板。
  搜索词不保存，搜索本身也不挂载功能或写配置。
* 详细日志默认关闭，控制台只留一行加载提示；在「插件自身」页签打开后，每个事件按 INFO / WARN / ERROR
  打成一行并带功能 id。控制台日志查看器只从它自己的开关打开那刻起收集，插件加载期的日志抓不到。
* 导入、导出与清除都针对 `data/storage/petal/some-settings-siyuan` 下的全部配置文件；集市包自定义图标
  只改本机显示并随思源同步，清除配置不会删掉它们。
* 两个重连功能都会重载前端；笔记内容在内核里随时落盘，重载不丢。
* 按作者屏蔽只作用于五个在线集市列表页签，已下载与可更新列表不受影响；名单与集市索引的 author 字段
  完全匹配（忽略大小写），列表被思源整块重绘后立即重新应用，数量与「全部被屏蔽」提示会跟着修正。
* 功能各自的边界：移动端行内代码复制按光标位置判定、只复制可见文本；书签跳转只接管整篇文档书签上的
  普通左键单击；录音浮窗只换界面（思源录音器没有暂停，只提供停止）；资源信息只对工作区
  `assets/…` 生效；代码片段高亮依赖思源自带的 highlight.js，缺失时退回纯文本。
* 「智能体工具调用显示细节」只读面板已收到的响应，对不上的调用不显示参数；
  「智能体回车发送」会盖掉默认的「智能体发送」快捷键。
