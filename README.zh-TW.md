# 一些設定

> 一批**可獨立啟停**的思源增強功能：每個設定項目都能單獨啟用或停用。

## 安裝

1. **思源市集** —— 開啟 **設定 → 市集**，找到「一些設定」直接安裝；後續更新也走這裡。
2. **發行版下載** —— 從 [Releases](https://github.com/wmy2981/some-settings-siyuan/releases) 下載
   `package.zip`，解壓縮到 `<工作空間>/data/plugins/some-settings-siyuan/`，讓 `plugin.json` 直接放在這個目錄下，
   然後重新啟動思源。
3. **自行編譯** —— 取得儲存庫後 `npm install`，再 `npm run build`（需要 Node 24 以上）；建置產物裡有
   `package.zip` 與扁平的 `dist/`，把其中任一個解壓縮到同一個目錄即可。

然後開啟 **設定 → 市集 → 已下載 → 一些設定 → 設定**，這是唯一的入口 —— 外掛不在頂欄、狀態列、
停靠欄註冊任何按鈕。

## 注意事項

* 設定改完即寫入該功能自己的設定檔，沒有儲存按鈕，關掉面板也不會遺失變更；也沒有單項重設，
  還原某一項只能匯出設定改好再匯入，或者清除全部。
* 面板會記住上次關閉時的頁籤，下次開啟回到那一頁；該頁籤已不可用時回到第一個頁籤。
* 搜尋框（桌面端在內容區頂部、行動端在標題下方）同時搜尋分類、功能與設定項目，命中的功能連同它的全部設定
  一起顯示並突顯；`Ctrl/Cmd + F` 或 `/` 聚焦，`Esc` 或輸入框裡的清除圖示只清空搜尋、不關面板。
  搜尋詞不儲存，搜尋本身也不掛載功能或寫入設定。
* 詳細日誌預設關閉，主控台只留一行載入提示；在「外掛本身」頁籤開啟後，每個事件依 INFO / WARN / ERROR
  打成一行並帶功能 id。主控台日誌檢視器只從它自己的開關打開那刻起收集，外掛載入期的日誌抓不到。
* 匯入、匯出與清除都針對 `data/storage/petal/some-settings-siyuan` 下的全部設定檔；市集套件自訂圖示
  只改本機顯示並隨思源同步，清除設定不會刪掉它們。
* 兩個重新連線功能都會重新載入前端；筆記內容在核心裡隨時寫入磁碟，重新載入不會遺失。
* 依作者封鎖只作用於五個線上市集清單頁籤，已下載與可更新清單不受影響；名單與市集索引的 author 欄位
  完全相符（忽略大小寫），清單被思源整塊重繪後立即重新套用，數量與「全部被封鎖」提示會跟著修正。
* 功能各自的邊界：行動端行內程式碼複製依游標位置判定、只複製可見文字；書籤跳轉只接管整篇文件書籤上的
  普通左鍵單擊；錄音懸浮視窗只換介面（思源錄音器沒有暫停，只提供停止）；資源資訊只對工作空間
  `assets/…` 生效；程式碼片段突顯依賴思源自帶的 highlight.js，缺少時退回純文字。
* 「智能體工具呼叫顯示細節」只讀面板已收到的回應，對不上的呼叫不顯示參數；
  「智能體按 Enter 傳送」會蓋掉預設的「智能體傳送」快速鍵。
